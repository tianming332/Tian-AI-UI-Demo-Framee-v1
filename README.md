# Framee · 设计稿播放器

把做好的手机 / 平板界面图，变成能点、能演示、能答辩的 App Demo。
不需要设置画板尺寸、缩放、安全区，导入图片就能演示。

## 三步用完

1. **导入界面图片**：把 PNG / JPG / WebP 拖进页面，或点「上传界面图片」多选。
   系统自动识别设计尺寸与机型，生成对应比例的真机外观。
2. **补充跳转关系**：在画面上拖一个框，选「点这里跳到哪一页」；
   也可以在右侧粘贴文本关系，一行一条，例如：

   ```
   首页 → 详情
   首页 → 发现
   发现 → 详情
   ```

3. **点「▶ 开始演示」**：点热区跳转，`←` 返回，`H` 显示可点区域，`F` 全屏，`Esc` 退出。

## 内置 10 页演示

首页点「打开 10 页示例」会载入原创生活方式 App「拾光」。示例已经包含：

- 10 张 `390 × 844` 手机界面；
- 22 个点击热区与基础转场；
- 启动、引导、首页、发现、详情、收藏、消息、通知、个人中心和设置；
- 详情页返回栈与底部导航跳转。

示例进入工作台后仍可重命名、改热区、增加页面并导出为自己的工程文件。

## 保存与交付

- 工程会自动保存在本浏览器，关掉再打开可继续。
- 点「导出工程」得到一个 `*.uiplay.json`（图片已内嵌），换电脑用「导入工程」直接打开。
- 若浏览器处于隐私模式无法本地保存，页面顶部会持续提示，请及时导出。

## 运行方式

需要 Node.js 20.19 或更新版本，双击对应启动文件：

- macOS：`start-mac.command`
- Windows：`start-windows.bat`

浏览器会自动打开 `http://localhost:3000`。手动运行：

```bash
npm install
npm run dev
```

打包与检查：

```bash
npm run build   # 类型检查 + 产物构建
npm run lint    # 仅类型检查
```

全程在浏览器本地运行，图片不会上传到任何服务器。
